# CardBoard

Sort cards into navigation groups and get a live wireframe prototype. No separate mapping step — the card sort and the prototype are two views of the same data.

## Getting Started

```bash
git clone https://github.com/jovana-andjelkovic/cardboard.git
cd cardboard
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
